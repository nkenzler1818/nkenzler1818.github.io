Pharmacovigilance RAG Pipeline

First-semester master's AI systems project automating pharmacovigilance workflows with multi-agent RAG.

Project Overview

Built for BNAN/MKTG 570, this project applies Retrieval-Augmented Generation and multi-agent orchestration to pharmacovigilance (the post-marketing drug safety function). The system automates routine analyst tasks like literature retrieval, FAERS trend analysis, and draft summary generation, while preserving human judgment for clinical signal validation.

Project Status

Phase 1 Complete

Project Proposal & Data Strategy

Defined the pharmacovigilance signal triage workflow, outlined data sources, and scoped the four agent roles.

Phase 2 Complete

Core RAG Pipeline Construction

Implemented document loading, chunking, embedding, and ChromaDB storage. Built Gradio interface and tuned retrieval hyperparameters.

Phase 3 Complete

Agentic Orchestration & Refinement

Implemented multi-agent workflow with meta-intelligent routing, four specialized strategies, and enhanced retrieval layer with Cohere reranking.

Phase 4 Complete

Final Presentation & System Delivery

Live demonstration delivered, fully commented notebook published, and critical analysis of performance, governance, and production deployment requirements completed.

Tech Stack

  • • Python - core pipeline and orchestration logic
  • • LangChain - agent framework and chain management
  • • ChromaDB - vector store for retrieved document embeddings
  • • OpenAI GPT-4 - primary language model for analysis and synthesis
  • • Cohere Rerank - relevance reranking for retrieval precision
  • • Gradio - interface layer for analyst interaction

Data Sources

  • • FDA FAERS adverse event reports
  • • PubMed abstracts
  • • FDA drug labels

Agent Architecture

The system coordinates four specialized agents, each scoped to a distinct step of the pharmacovigilance workflow:

  • • Research Retrieval - queries PubMed and FDA labels for relevant literature
  • • Adverse Event Analysis - surfaces trends and signal patterns from FAERS data
  • • Regulatory Context - cross-references label indications, warnings, and prior actions
  • • Synthesis - generates structured regulatory summaries for analyst review

System Performance & Results

The system's routing intelligence is validated through measurable performance tradeoffs documented during development. Simple PRR lookups resolve in 2–3 seconds via the Naive chain; comprehensive multi-agent analyses take 8–12 seconds with four parallel LLM calls, a deliberate tradeoff and not an oversight. The on-topic relevance guardrail, running on every query via gpt-4o-mini, achieves over 95% classification accuracy at roughly 1/20th the cost of gpt-4o, demonstrating that right-sizing AI to task complexity is itself a performance strategy.

The system processes queries against 17,313 FAERS rows across five document types, with parent-child chunking (2,000/400 chars) ensuring both precise semantic retrieval and rich contextual generation in the final response.

AI Judgment: Automation vs. Human Control

PharmaSignal RAG automates the initial triage phase (literature retrieval, FAERS trend analysis, and draft summary generation) while deliberately preserving human judgment for clinical signal validation. The system's guardrails encode this boundary directly: queries asking for medical advice or clinical decisions are blocked, not answered. This is intentional architecture, not a limitation. In regulated environments like pharmacovigilance, understanding where AI should stop is as important as knowing where it can help. The system is designed to accelerate analyst workflows, not replace analyst judgment.

Learnings & Future Iterations

The most instructive limitation is the absence of conversation memory: each query is stateless. In a real analyst workflow, follow-up questions like "what about the ROR for that drug?" are essential, but the current architecture requires users to restate context every call. A production version would implement context windowing (last 5–10 exchanges) and a dynamic knowledge base refresh pipeline for quarterly FAERS updates. The architecture is right; operational completeness is the next iteration.

Native × Japan Market Entry Presentation

Market Entry Strategy Presentation

Project Overview & Market Opportunity

Japan’s beauty market is worth $32 billion, yet deodorant penetration sits at only 55%-far below the global average of 92%. This gap exists because of cultural factors: minimal odor expectations due to daily bathing habits and genetic factors (ABCC11 gene variation means less body odor for East Asian populations). But this also means tremendous upside for the right brand entering at the right time. Native, as a premium natural deodorant aligned with wellness trends, has a real opportunity to capture share in Japan’s growing consciousness around freshness and personal care.

The Regulatory Barrier Becomes a Strategic Advantage

Japan classifies deodorants containing antiperspirant actives as quasi-drugs, requiring 12–18 months of Ministry of Health, Labour and Welfare (MHLW) approval. Instead of treating this as a blocker, the strategy uses it as a sequencing tool: Phase 1 launches Native as a cosmetic-classified body fragrance/deodorant through e-commerce (Amazon Japan, Rakuten) to build brand awareness and consumer reviews. Phase 2 runs the regulatory approval process in parallel while gathering market data. Phase 3, upon approval, transitions to full deodorant launch in retail channels with Japan-exclusive formulations.

Cultural Positioning: "Kirei" Over Function

The biggest insight: don’t sell deodorant in Japan. Sell "kirei"-the concept of freshness, cleanliness, and wholeness. Position Native as a wellness product aligned with Japanese beauty standards around minimal scent, natural ingredients, and purity. The marketing, scent profiles, and retail placement all emphasize wellness category positioning, not functional odor control (which carries cultural stigma). This required repositioning the entire brand narrative for the market.

Why This Matters

This case demonstrates sophisticated strategic thinking: how to navigate regulatory constraints as sequencing opportunities, how cultural understanding reshapes positioning, and how phased rollout enables data-driven decisions at each stage. It shows the ability to synthesize market research, regulatory environment, competitive positioning, and cultural adaptation into a coherent go-to-market strategy. This is the kind of multi-variable decision-making that matters in real marketing leadership roles.

Marketing Research Methods

AI Trust Research: Full Presentation

Project: AI Trust in Digital Search Platforms

In MKTG 572 Marketing Research for Managers, our team designed and executed a controlled experiment investigating how AI integration transparency affects user trust in digital search platforms. The core research question was whether presenting an AI advisory feature as optional and hidden rather than prominently displayed would affect trust levels. Our hypothesis predicted that AI shown as an optional, collapsible feature would yield higher trust than AI forced and visible by default. We tested this against a realistic food discovery search interface using a between-subjects experimental design.

Experimental Design & Methodology

We ran a between-subjects experiment with two conditions: AI Present (AI expanded by default, prominently visible) and AI Optional (AI collapsed by default, accessible via a "Try AI Advisor" button). Participants interacted with the search interface and completed a validated 7-point trust scale. Cronbach's alpha equaled 0.78, confirming acceptable scale reliability. The sample had an average age of 42, reflecting a broad adult consumer perspective. We ran independent-samples t-tests in SPSS to compare trust scores across conditions, with Cohen's d calculated to assess practical significance beyond statistical thresholds.

Data Collection & Sample

Participant data was collected through Cloud Research, a professional research panel platform. Cloud Research enabled efficient recruitment of a representative sample with an average age of 42, reflecting a broad adult consumer perspective. This paid panel methodology is standard in rigorous marketing research for avoiding the selection bias common in convenience samples, ensuring that results generalize beyond a student or self-selected population.

Key Findings: Null Result, Strong Insight

Results showed no statistically significant difference in trust between conditions (AI Present M = 3.93 out of 7, AI Optional M = 3.76 out of 7; p = 0.489; Cohen's d = 0.14, indicating small effect size). Our hypothesis was not supported. However, qualitative responses clarified why: participants reported distrust driven by accuracy concerns and lack of control, not by AI visibility. Representative quotes captured the pattern: "I don't like how the first page is just all AI instead of actual results" and "I do not trust AI systems to make critical decisions for me, I always have the last word."

The critical finding: trust was driven by perceived accuracy, transparency, and user control rather than whether AI was visually present or hidden.

Business Implications & Strategic Insight

These findings challenge the common UX assumption that surfacing AI features more prominently increases trust. If trust is governed by accuracy and control rather than visibility, brands adding AI to consumer experiences should prioritize explainability and user override capabilities, not AI prominence. Future research should strengthen the manipulation by showing ranking logic explicitly and extend to higher-stakes decisions where trust effects would be more pronounced. A null result here is itself informative for any product team making AI integration decisions.

Research Rigor & Data Literacy

This project demonstrates full-cycle quantitative research literacy: experimental design, Qualtrics survey construction, SPSS statistical analysis including t-tests, Cronbach's alpha, and effect sizes, plus evidence-based interpretation. Critically, we showed the discipline to accurately report and learn from null results. Knowing when data contradicts your hypothesis is as important as knowing when it confirms it. This is the foundation of evidence-based decision-making in any organization.

Methodology & Tools

  • • Design: Between-subjects experiment, 2 conditions
  • • Scale: 7-point trust measure (Cronbach's α = 0.78)
  • • Qualtrics - survey and experimental administration platform
  • • Cloud Research - participant recruitment and data collection
  • • SPSS - t-tests, Cronbach's alpha, Cohen's d

Capstone Project

A dynamic business simulation showcasing market strategy, competition, and adaptive decision-making over time.

Project Overview

In this capstone, I participated in a weekly business simulation called the Business Strategy Game (BSG), where teams operated virtual athletic footwear companies and competed directly against one another for market share. Each Sunday, the simulation processed all team decisions and generated performance reports, which we then analyzed before submitting updated strategies for the following week.

At the outset, teams selected a strategic positioning, choosing whether to compete as a high-quality, premium brand or a lower-cost, higher-volume producer. I served as the designated decision coordinator, responsible for consolidating team input and submitting a unified strategy each week to avoid conflicting changes and ensure consistency in execution.

Weekly Competitive Adjustments

Each week, I analyzed the Sunday performance reports to assess how our decisions compared against competing teams. By Year 13, execution issues began to surface, particularly around quality planning and channel alignment. These challenges resulted in a sharp decline in our ranking, as shown in the early scoreboard results (Image A).

Identifying the Underlying Problem

To diagnose the root cause of our decline, I conducted a deeper competitive analysis using Comparative Competitive Efforts reports (Image B). This analysis revealed that:

  • • Our private-label S/Q rating fell below retailer requirements, eliminating sales in that segment
  • • Pricing and celebrity appeal lagged behind competitors with similar product quality
  • • An aggressive growth strategy, supported by short-term debt, assumed revenue that did not materialize

This comparative benchmarking clarified that the issue was not a single decision, but a misalignment between production quality, channel requirements, and financial assumptions.

Finding the Strategic Opportunity

As I expanded the analysis to include subsequent rounds (Image C), a broader industry pattern became clear. Most teams were aggressively competing in internet sales, creating a saturated and highly competitive environment. In contrast, wholesale distribution was significantly underutilized across the industry.

Recognizing this gap, I identified wholesale as a strategic opportunity to scale volume, reduce direct competition, and stabilize performance while maintaining selective internet sales.

Strategy Shift and Execution

Based on these insights, our team devised and implemented a coordinated strategy shift focused on execution discipline and channel alignment:

  • • Corrected S/Q ratings to meet retailer thresholds
  • • Adjusted TQM and Six Sigma investments to stabilize quality
  • • Repositioned pricing to emphasize affordability at scale
  • • Increased marketing and celebrity appeal to reinforce brand credibility
  • • Shifted production emphasis toward wholesale distribution

These changes were executed over multiple rounds, with each decision cycle aligned to reinforce the broader strategy (Image D).

Recovery and Performance Outcomes

The impact of the strategy shift became visible quickly. By Year 15, our ranking rebounded sharply, jumping from near the bottom of the scoreboard to the top tier in a single year (Image E). Performance gains continued through the final rounds of the simulation.

By Year 20, our company achieved:

  • • Stock price of $559, compared to competitors as low as $21
  • • Earnings per share of $23, the highest in the industry
  • • Return on equity of 43 percent
  • • A+ credit rating and A+ image rating
  • • $1.8 million in total sales (Image F)
  • • Second place finish in the class

Looking Back and Moving Forward

Beyond the results, this project reinforced my confidence in stepping into a leadership role and driving performance under pressure. In concrete terms, by Year 20, we secured first place for that final year (Image G) and finished second overall in the entire simulation (Image H). We turned a slow start into a strong upward trajectory, proving that a well-executed strategic pivot can achieve top-tier results.

But more than just the numbers, this experience was about navigating early setbacks, identifying the right strategic pivot, and coordinating execution across multiple rounds. It demonstrated my ability to lead data-driven decision-making and elevate a team's performance to a high level. Ultimately, that's the kind of impact I aim to bring into any real-world marketing scenario: turning insights into action and guiding a team to success.

Campaign Efficiency Case Study

Evaluating webinars, regional events, and digital campaigns using SQL + visualization

Context

This project represents my first hands-on exploration of working with SQL and relational data in practice. Rather than starting with a defined business problem or assignment, I wanted to experience the full analytical flow end to end and understand what it feels like to move from raw data to insight.

To do this, I intentionally jumped in with minimal constraints and focused on learning how data moves through a system, how queries shape outputs, and how results can be translated into something interpretable and visual.

Project Overview

For this project, I worked with a fully synthetic dataset generated by OpenAI's ChatGPT. I did not provide instructions for the structure or contents of the dataset, which made the data effectively random and unpredictable.

This setup allowed me to focus on adapting to an unfamiliar dataset, integrating it into a relational database, and determining how to extract meaningful signals through analysis rather than controlling inputs from the start.

The Data

The dataset consists of synthetic campaign, lead, and opportunity records modeled in a simplified enterprise-style structure. While the data itself is artificial, it reflects common relationships found in real-world marketing and sales environments.

All analysis was performed after the data was imported into MySQL. From there, I defined metrics and calculations to evaluate pipeline, cost, and ROI by campaign type. All insights were derived directly from SQL query outputs.

Analysis Flow

  • • Imported a synthetic dataset into MySQL
  • • Joined campaign, lead, and opportunity tables to establish relational context
  • • Aggregated pipeline, cost, and ROI metrics by campaign type using SQL
  • • Analyzed relative efficiency and scale tradeoffs across campaign types
  • • Used Gemini to generate a visualization from the analyzed outputs
  • • Translated the visualization into a structured JSON prompt
  • • Integrated the interactive visualization directly into this website

SQL & Data Foundation

This analysis is backed by a relational SQL data model that connects campaigns, leads, and opportunities to evaluate pipeline impact and ROI. The visualization is generated from an aggregated dataset produced through SQL joins and calculations.

What I Took Away

This project was my first opportunity to work through a complete analytical workflow without a prescribed path. Starting with unfamiliar data forced me to think less about getting a specific answer and more about understanding structure, relationships, and tradeoffs.

Working through this process helped me see how tools like SQL and visualization fit together, not as isolated skills, but as part of a broader way of thinking about data. It also clarified where deeper technical fluency can unlock better questions, clearer insights, and more confident decision-making as I continue developing in marketing.
